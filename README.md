# 치열 3D 개략 모형

브라우저에서 돌려 볼 수 있는 치열 3D 모형입니다. `index.html`을 열면 됩니다.

- 치료 단계 전환: 현재, 발치 예정, 치료 후
- 표시 전환: 위턱, 아래턱, 잇몸, 뼈, 빈 자리
- 치아나 뼈를 누르면 해당 부위 설명이 나옵니다.

사진과 엑스레이, 견적서를 보고 옮긴 설명용 모형이며 진단 자료가 아닙니다.

치아 22개와 뿌리만 남은 치아 3개는 CT에서 뽑은 실제 모양이고 `ct-teeth.js`에 들어 있습니다. 이 파일은 [`tools/ct3d`](tools/ct3d/)의 스크립트로 만들었고, 파일이 없으면 `index.html`은 표준형 치아로 그립니다. 임플란트와 보철은 표준형입니다.

3D 라이브러리(three.js)와 글꼴을 CDN에서 불러오므로 인터넷 연결이 필요합니다.
